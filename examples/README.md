# Beispiele

Fertige Bausteine für ein typisches Setup (Hauptleitung DSL über ein Modem, Backup über Mobilfunk, Glasfaser
vorbereitet). Die Entitäts-IDs sind Platzhalter – ersetze sie durch deine eigenen.

| Datei | Wohin |
|---|---|
| `detailansichten-aktion.yaml` | *Entwicklerwerkzeuge → Aktionen* → „In YAML-Modus wechseln“ → einfügen → *Aktion ausführen*. Setzt Leitungsnamen und Detailansichten (dasselbe wie *HomeLines → Konfigurieren*). |
| `internet-seite.yaml` | Eine **Dashboard-Seite**: *Dashboard bearbeiten → ⋮ → Rohkonfigurations-Editor*. Nur den Block einer Seite (`- title: …`) ersetzen oder ergänzen, nicht das ganze Dashboard. |
| `mini-karte.yaml` | Eine **Karte**: *Karte hinzufügen → manuell* bzw. *Karte bearbeiten → Code-Editor*. |

Alle Karten lassen sich auch ohne YAML im grafischen Editor einstellen.
